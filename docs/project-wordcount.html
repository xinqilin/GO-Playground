字詞統計

把一段文字倒進去，數出哪些字最常出現。

看圖

核心程式

func Top(counts map[string]int, n int) []WordCount {
	all := make([]WordCount, 0, len(counts))
	for w, c := range counts {
		all = append(all, WordCount{w, c})
	}
	slices.SortFunc(all, func(a, b WordCount) int {
		return cmp.Or(
			cmp.Compare(b.Count, a.Count), // 次數多的在前
			cmp.Compare(a.Word, b.Word),   // 次數一樣就照字母
		)
	})
	return all[:min(n, len(all))]
}

輸入（測試用的範例文字）

Go is fun. Go is fast!
The gopher says: go, go, GO.

-top 3 的輸出

行數 2，字數 12，字元數 50
go       5
is       2
fast     1

工程師筆記

  • map 的走訪順序不固定，輸出前一定要排序；排序條件要能分出先後，結果才會穩定。
  • cmp.Or（Go 1.22）回傳第一個不是零值的參數，拿來串多個排序條件剛好。
  • strings.Fields 依空白切字；中文句子之間沒有空白，要做中文斷詞得用專門的套件。
  • bufio.Scanner 預設一行最多 64KB；要處理更長的行，用 sc.Buffer 調大。
  • %-8s 的寬度是用 rune 數算的，中文字在終端機佔兩格，對齊會跑掉。
