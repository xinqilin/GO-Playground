測試

測試是自動檢查員：每次改完程式跑一次 go test，該檢查的地方它全部再看一遍。

看圖

最小範例

textutil/textutil_test.go（節錄）

func TestReverse(t *testing.T) {
	tests := []struct {
		name, in, want string
	}{
		{"英文", "Go", "oG"},
		{"中文", "你好世界", "界世好你"},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			if got := Reverse(tt.in); got != tt.want {
				t.Errorf("Reverse(%q) = %q, want %q", tt.in, got, tt.want)
			}
		})
	}
}

func BenchmarkReverse(b *testing.B) {
	s := strings.Repeat("Go語言", 100)
	for b.Loop() { // Go 1.24 起
		Reverse(s)
	}
}

工程師筆記

  • 測試檔名以 _test.go 結尾，函式寫成 func TestXxx(t *testing.T)；go test ./... 一次跑全部。
  • t.Errorf 記錄失敗後繼續跑；t.Fatalf 記錄後馬上結束這個測試。輔助函式開頭呼叫 t.Helper()，失敗訊息才會指向呼叫的那一行。
  • Example 的 // Output: 會被比對，等於一份不會過期的文件。
  • Benchmark 用 b.Loop()（Go 1.24）；加 -benchmem 可以看每次操作配置了幾次記憶體。
  • Fuzz 平常只跑 f.Add 的種子；加 -fuzz 才會隨機產生輸入，找到的失敗案例存在 testdata/fuzz，之後每次 go test 都會重跑。
  • -race 和 -cover 是隨手就該加的旗標；牽涉時間的並行程式，可以用 testing/synctest（Go 1.25）讓測試不用真的等。
