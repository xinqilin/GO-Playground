陣列與切片

陣列是一排固定的格子；slice 是看向這排格子的一扇窗。

看圖

最小範例

func main() {
	arr := [5]int{10, 20, 30, 40, 50}
	s := arr[1:4] // 看見 20 30 40
	s[0] = 99     // 改到的是 arr
	fmt.Println(arr, len(s), cap(s))

	head := []int{1, 2, 3, 4}
	part := head[:2]
	part = append(part, 99) // 容量夠：蓋掉 head[2]
	fmt.Println(head, part)

	safe := head[:2:2]
	safe = append(safe, 7) // 容量不夠：換新陣列
	fmt.Println(head, safe)
}

輸出

[10 99 30 40 50] 3 4
[1 2 99 4] [1 2 99]
[1 2 99 4] [1 2 7]

工程師筆記

  • 陣列長度是型別的一部分，[3]int 和 [4]int 是不同型別；指定或傳參數都會複製整個陣列。實務上幾乎都用 slice。
  • slice 是一個小小的描述子（ptr、len、cap）。傳進函式只複製描述子：函式裡改元素，呼叫端看得到；但函式裡 append 的結果要回傳出去。
  • append 一定要接回傳值：s = append(s, x)。
  • 用 s[low:high:max] 限制容量，避免 append 蓋到別人的資料。從大 slice 切出一小段要長期保存，用 slices.Clone 複製，否則整個大陣列都會留在記憶體裡。
  • nil slice 和空 slice 的 len 都是 0，也都能 append；差別在 JSON：nil 編成 null，空 slice 編成 []。
  • 知道大概大小時先 make([]T, 0, n) 預留容量，減少搬家。新容量是多少是 runtime 的實作細節：在 Go 1.27 上，nil 的 []int 第一次 append 就拿到 cap 4。
