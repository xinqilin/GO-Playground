值、變數與運算

變數是貼了名字的盒子。你可以把值放進去、拿出來用，也可以換成新的值；但一個盒子一次只裝得下一個值，放進新的，舊的就不見了。

本章你會學到

  • 值有種類，叫做型別：整數、小數、文字、真假各是不同的型別。
  • 用變數替值取名字，用 := 建立變數，用 = 換成新的值。

1. 值與型別

程式處理的每一筆資料都叫做值（value）：便當的價格 85、體重 3.5 公斤、菜名「排骨便當」、「是不是會員」的答案。值有不同的種類，叫做型別（type）。最常用的四種是：

func values() {
	fmt.Println(85)
	fmt.Println(3.5)
	fmt.Println("排骨便當")
	fmt.Println(true)
}

輸出

85
3.5
排骨便當
true

fmt.Printf 是依照格式來印的 Println：格式裡的 %v 換成值、%T 換成值的型別名稱、\n 是換行。用它來看看每個值的型別：

func valueTypes() {
	fmt.Printf("%v 是 %T\n", 85, 85)
	fmt.Printf("%v 是 %T\n", 3.5, 3.5)
	fmt.Printf("%v 是 %T\n", "排骨便當", "排骨便當")
	fmt.Printf("%v 是 %T\n", true, true)
}

輸出

85 是 int
3.5 是 float64
排骨便當 是 string
true 是 bool
  • int：整數（integer），沒有小數點，可以是負數。數量、價格（以元計）、年齡都用它。
  • float64：有小數點的數。名稱裡的 64 是它佔用的空間大小，現在不用管。
  • string：文字，寫在雙引號裡。字串（string）的意思是「一串字」。
  • bool：只有 true（真、是）和 false（假、否）兩個值，用來表示「是不是」。名稱來自數學家 Boole。

型別決定運算的意思

func textVsNumber() {
	fmt.Println(85 + 3)
	fmt.Println("85" + "3")
	fmt.Println("排骨" + "便當")
}

輸出

88
853
排骨便當

同樣是 +：兩個數字是相加，得到 88；兩段文字是接起來，得到 853。"85" 有雙引號，它是「8 和 5 這兩個字」，不是八十五。從鍵盤讀進來的東西都是文字，要先轉成數字才能計算，這在 02 輸入與輸出會學到。

2. 變數

func variables() {
	price := 85
	qty := 3
	fmt.Println(price * qty)

	var name string = "小明"
	fmt.Println(name, "買了", qty, "個便當")
}

輸出

255
小明 買了 3 個便當

price := 85 讀作「建立一個叫 price 的變數，放進 85」。:= 會依照右邊的值決定盒子的型別：85 是整數，所以 price 是 int，之後只能裝整數。另一種寫法 var name string = "小明" 把型別寫出來，意思一樣；兩種寫法在 01 變數、常數與型別會詳細比較。

用變數的好處是：同一個值只寫一次，用名字說明它的意思。price * qty 比 85 * 3 好懂得多；價格改了，也只要改一個地方。

變數的名字由英文字母、數字和底線組成，不能以數字開頭，而且分大小寫（price 和 Price 是兩個不同的變數）。習慣上用小寫開頭，好幾個字連在一起時，後面每個字的開頭大寫，例如 unitPrice、totalCount。

Go 對變數的三個規定

第一，建立了變數就一定要用到。寫到一半的程式常常會撞到這一條：

package main

import "fmt"

func main() {
	price := 85
	qty := 3
	fmt.Println(price)
}

編譯錯誤

./main.go:7:2: declared and not used: qty

第二，同一個名字只能建立一次。要換成新的值用 =（第 3 節），不是再 := 一次：

package main

import "fmt"

func main() {
	price := 85
	price := 90
	fmt.Println(price)
}

編譯錯誤

./main.go:7:8: no new variables on left side of :=

第三，盒子的型別不能改。裝整數的盒子不能放進文字：

package main

import "fmt"

func main() {
	price := 85
	price = "九十"
	fmt.Println(price)
}

編譯錯誤

./main.go:7:10: cannot use "九十" (untyped string constant) as int value in assignment

這些規定看起來很囉嗦，但它們都在幫你：沒用到的變數通常代表程式寫錯了或沒寫完；型別不能改，就不會在某個地方不小心把價格變成文字。錯誤在執行之前就被抓出來，比跑到一半才出錯好得多。

3. 改變變數的值

func reassign() {
	count := 0
	fmt.Println(count)
	count = count + 1
	fmt.Println(count)
	count = count + 1
	fmt.Println(count)
}

輸出

0
1
2

在數學課，count = count + 1 是不可能成立的式子。但在程式裡，= 叫做指定（assignment），意思是一個動作：先把右邊算出來，再把結果放進左邊的盒子。所以這一行讀作「拿出 count 目前的值，加 1，再放回 count」。每執行一次，count 就多 1。這種「每次加 1 來數數」的變數叫計數器，先修 3 的迴圈會一直用到。

注意順序：右邊用的是執行這一行之前的值。第一次 count 是 0，算出 1 放回去；第二次 count 已經是 1，算出 2。

簡寫

func shortcuts() {
	points := 10
	points += 5
	fmt.Println(points)
	points -= 3
	fmt.Println(points)
	points *= 2
	fmt.Println(points)
	points++
	fmt.Println(points)
}

輸出

15
12
24
25

「拿自己來算，再放回自己」太常見了，所以有簡寫：points += 5 就是 points = points + 5，-=、*=、/= 也一樣。points++ 是加 1 的簡寫，points-- 是減 1。在 Go 裡 ++ 自己就是一整行，不能寫在其他算式中間。

4. 交換兩個變數

桌上有兩杯飲料，a 杯是紅茶、b 杯是綠茶，要把它們對調。直覺的寫法是這樣：

func wrongSwap() {
	a := "紅茶"
	b := "綠茶"
	a = b
	b = a
	fmt.Println(a, b)
}

輸出

綠茶 綠茶

兩杯都變成綠茶了。一行一行看：a = b 把綠茶放進 a，a 原本的紅茶就被換掉、不見了；接著 b = a 把 a 現在的值（綠茶）放進 b。這就是第 3 節說的：盒子放進新的值，舊的值就不見了。

現實中對調兩杯飲料，需要第三個空杯子。程式也一樣：

func tempSwap() {
	a := "紅茶"
	b := "綠茶"
	tmp := a
	a = b
	b = tmp
	fmt.Println(a, b)
}

輸出

綠茶 紅茶

上圖就是這段程式每一步之後的狀態。Go 另外提供一個方便的寫法，一次指定好幾個變數：

func goSwap() {
	a := "紅茶"
	b := "綠茶"
	a, b = b, a
	fmt.Println(a, b)
}

輸出

綠茶 紅茶

a, b = b, a 會先把右邊的值全部拿好（綠茶、紅茶），才依序放進左邊，所以不會有被蓋掉的問題。實際寫 Go 時都用這種寫法；但先懂 tmp 的版本，才知道為什麼直覺的寫法會錯。練習 6 是三個人換座位的版本。

5. 算術與整數除法

func arithmetic() {
	fmt.Println(7 + 2)
	fmt.Println(7 - 2)
	fmt.Println(7 * 2)
	fmt.Println(7 / 2)
	fmt.Println(7 % 2)
	fmt.Println(7.0 / 2)
}

輸出

9
5
14
3
1
3.5

加、減、乘的結果都和數學課一樣。除法要特別注意：兩個整數相除，結果還是整數，小數部分直接丟掉（不是四捨五入），所以 7 / 2 是 3。只要其中一邊是小數，例如 7.0 / 2，結果才會是 3.5。

% 是餘數（remainder），也就是除不盡剩下的部分：7 除以 2 得 3 餘 1，所以 7 % 2 是 1。整數除法和餘數常常一起用：

func splitBill() {
	total := 100
	people := 3
	fmt.Println("每人", total/people, "元")
	fmt.Println("剩下", total%people, "元")
}

func duration() {
	minutes := 135
	fmt.Println(minutes/60, "小時", minutes%60, "分")
}

輸出

每人 33 元
剩下 1 元
2 小時 15 分

135 分鐘裡有幾個完整的 60 分鐘？135 / 60 是 2；剩下的 135 % 60 是 15。同樣的方法可以把秒換成分秒、把天數換成幾週又幾天（練習 2）、算找零要幾枚硬幣（練習 5）。餘數還有一個常見的用途：n % 2 是 0 就是偶數，是 1 就是奇數。

整數和小數不能直接一起算

package main

import "fmt"

func main() {
	price := 85
	rate := 0.9
	fmt.Println(price * rate)
}

編譯錯誤

./main.go:8:14: invalid operation: price * rate (mismatched types int and float64)

price 是 int，rate 是 float64，型別不同（mismatched types），Go 不會自動幫你轉換。要先明確地把其中一個轉成另一個的型別：

func discount() {
	price := 85
	rate := 0.9
	fmt.Println(float64(price) * rate)
	fmt.Println(int(float64(price) * rate))
}

輸出

76.5
76

float64(price) 把 85 轉成小數 85.0，乘以 0.9 得到 76.5。int(…) 再把小數轉回整數，小數部分一樣直接丟掉，得到 76。Go 要你自己寫出轉換，是為了讓「這裡會丟掉小數」這件事在程式裡看得見。小數的計算有時會有很小的誤差，詳細的原因在 01 章的浮點數。

最後提醒一次 先修 1 看過的規則：先乘除後加減，有括號的先算。不確定的時候就加括號，多加的括號不會出錯。

6. 比較與邏輯

func compare() {
	price := 85
	fmt.Println(price > 80)
	fmt.Println(price == 90)
	fmt.Println(price != 90)
	fmt.Println(price <= 85)
	fmt.Println("排骨" == "排骨")
}

輸出

true
false
true
true
true

比較運算問的是一個是非題，答案是 bool：> 大於、< 小於、>= 大於或等於、<= 小於或等於、== 等於、!= 不等於。注意「等於」是兩個等號；一個等號是第 3 節的指定，意思完全不同。

真實的規則常常不只一個條件，例如「12 歲以下或 65 歲以上可以買半票」「會員而且消費滿 100 元才打折」。這時用邏輯運算把條件組合起來：

func logic() {
	age := 70
	member := false
	total := 120
	fmt.Println(age < 12 || age >= 65)
	fmt.Println(member && total >= 100)
	fmt.Println(!member)
}

輸出

true
false
true
  • 第一行：70 歲，age < 12 是 false，age >= 65 是 true；|| 只要一邊成立，所以結果是 true，可以買半票。
  • 第二行：消費 120 元已經滿 100，但不是會員；&& 要兩邊都成立，所以是 false，不打折。
  • 第三行：!member 是「不是會員」，member 是 false，反過來就是 true。

把中文的規則翻成程式時，一個條件一個條件寫，再用 &&、|| 接起來。「12 歲以下」要想清楚包不包含 12：題目說「未滿 12 歲」就是 age < 12，說「12 歲以下」通常是 age <= 12。邊界上的那一個值，是最容易寫錯的地方，練習 3 的測試就特別檢查了 11、12、64、65 這幾個年齡。下一章，這些 true 和 false 會用來決定程式要走哪一條路。

7. 追蹤表

程式的結果不對時，最可靠的方法是把自己當成電腦，一行一行照著做，把每個變數的值記下來。記錄用的表格叫追蹤表（trace table）：每一行程式一列，每個變數一欄，格子裡寫執行完這一行之後變數的值。第 4 節的圖就是一張追蹤表。

先不要執行，用紙筆追蹤這段程式，猜猜看它會印出什麼：

func traceMe() {
	x := 3
	y := x * 2
	x = y + 1
	y = x - y
	fmt.Println(x, y)
}
程式xy說明
x := 33y 還不存在
y := x * 236用 x 目前的值 3
x = y + 176x 的 3 被換成 7
y = x - y71右邊用的是新的 x（7）和舊的 y（6）

輸出

7 1

追蹤時最常犯的錯，是用了「看起來」的值，而不是「這時候」的值。最後一行的 x 已經是 7，不是一開始的 3。只要每一步都回頭查表格上一列的值，就不會出錯。

追蹤表看起來很笨，卻是寫程式的人一輩子都在用的技巧。程式的結果和你預期的不同時，就是腦中的追蹤表和電腦實際做的事不一樣了；找出是哪一列開始不同，就找到了 bug。程式更長的時候，可以在中間加幾行 fmt.Println 印出變數，讓電腦替你填表格，先修 4 會再練習這個方法。練習 4 是一題追蹤題。

常見錯誤

1. 把 = 當成「等於」

一個等號是指定（放進去），兩個等號才是比較。count = count + 1 是動作，不是等式；問「price 是不是 90」要寫 price == 90。

2. 忘了整數除法會丟掉小數

7 / 2 是 3，18 / 20 是 0。需要小數時，先用 float64(…) 轉換再除；先除再轉換，小數早就被丟掉了。練習 7。

3. 把文字的數字當成數字

"85" + "3" 是 "853"。有雙引號的就是文字，不能拿來算數。

4. 整數和小數直接一起算

Go 不會自動轉換型別，會得到 mismatched types 的編譯錯誤（第 5 節）。用 float64(…) 或 int(…) 明確轉換。

5. := 和 = 用錯

第一次建立變數用 :=，之後改值用 =。對已經存在的變數再用 := 會得到 no new variables；對還沒建立的變數直接用 =，會得到 undefined。

6. 先覆蓋了，後面才要用

放進新的值，舊的值就不見了。交換、輪替這類操作，要先用 tmp 存起來，或用 a, b = b, a 一次指定（第 4 節、練習 6）。

練習

題目在 exercises/pre-2-values/exercises.go，做法和先修 1 的練習一樣。

go test ./exercises/pre-2-values/                    # 跑全部練習

這幾題的函式會用 return 一次交回好幾個值，例如 return 33, 1，順序就是函式第一行括號裡寫的順序。函式的寫法在先修 4 會正式介紹。

  1. 入門練習 1：經過幾分鐘

    算出同一天裡兩個時間之間經過了幾分鐘。

    func Elapsed(startH, startM, endH, endM int) int {
	// TODO: 實作
	return 0
}

    測試：TestElapsed。

    提示

    直接把小時減小時、分鐘減分鐘，遇到 50 分到 5 分就麻煩了。先把兩個時間都換成「從 0 點開始算的第幾分鐘」：小時乘以 60 再加分鐘，然後相減。可以先用兩個變數存起來，讓程式比較好讀。

  2. 入門練習 2：幾週又幾天

    把天數換成幾週又幾天。

    func WeeksAndDays(days int) (weeks, rest int) {
	// TODO: 實作
	return 0, 0
}

    測試：TestWeeksAndDays。

    提示

    和第 5 節把分鐘換成小時的做法一樣，一週是 7 天。

  3. 入門練習 3：半票

    未滿 12 歲，或 65 歲以上，可以買半票。

    func IsHalfFare(age int) bool {
	// TODO: 實作
	return false
}

    測試：TestIsHalfFare。

    提示

    比較運算的結果本身就是 bool，可以直接 return。「未滿 12」包不包含 12？「65 歲以上」包不包含 65？

  4. 進階練習 4：追蹤

    不要執行那段程式，畫一張追蹤表，把最後 a、b、c 的值填進 return。

    func Predict() (a, b, c int) {
	// TODO: 把 0, 0, 0 換成你追蹤出來的答案
	return 0, 0, 0
}

    測試：TestPredict。

    提示

    表格要有 a、b、c 三欄，一共六列。第二、三列用到整數除法和餘數：17 除以 5 是多少、餘多少？最後一列的 b 已經不是一開始的值了。

  5. 挑戰練習 5：找零

    找零時要用最少的硬幣。台灣常用的硬幣是 50 元、10 元、5 元、1 元。

    func Coins(amount int) (c50, c10, c5, c1 int) {
	// TODO: 實作
	return 0, 0, 0, 0
}

    測試：TestCoins。

    提示

    從最大的硬幣開始：c50 = amount / 50 是 50 元要幾枚，amount % 50 是剩下還要找的錢。把剩下的錢放回 amount，再用同樣的方法算 10 元、5 元，最後剩下的就是 1 元的枚數。具名的回傳值（c50、c10…）可以直接當變數用。

  6. 找錯練習 6：換座位

    三個人往前換一格座位，結果有一個人不見了。

    func Rotate(a, b, c string) (string, string, string) {
	a = b
	b = c
	c = a
	return a, b, c
}

    測試：TestRotate。

    提示

    畫追蹤表：執行到 c = a 時，a 裝的已經是誰了？可以先用 tmp 存起來，或用第 4 節一次指定的寫法。

  7. 找錯練習 7：出席率

    出席率是出席次數除以總次數再乘 100，但除了全勤以外，算出來全部是 0。

    func Attendance(part, total int) float64 {
	return float64(part / total * 100)
}

    測試：TestAttendance。

    提示

    追蹤一次 part / total * 100：18 / 20 是兩個整數相除，得到 0，乘以 100 還是 0，最後轉成 float64 也只是 0.0。轉換要放在除法之前。

重點回顧

  • 每個值都有型別：int 整數、float64 小數、string 文字、bool 真假。
  • 型別決定運算的意思：數字的 + 是相加，文字的 + 是接起來。
  • := 建立變數，= 換成新的值；變數建立了就要用，型別不能改。
  • = 是先算右邊、再放進左邊；放進新的值，舊的就不見了。
  • 交換兩個變數要用 tmp，或用 a, b = b, a。
  • 兩個整數相除會丟掉小數；% 是餘數。
  • int 和 float64 不能直接一起算，要用 float64(…)、int(…) 轉換。
  • 比較的結果是 bool；&& 兩邊都要成立，|| 一邊成立就好，! 反過來。== 是比較，= 是指定。
  • 追蹤表一行一行記下變數的值，是理解程式和找 bug 最基本的方法。
