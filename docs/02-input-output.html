輸入與輸出

程式是一台果汁機：從 io.Reader 倒進原料，從 io.Writer 倒出結果。

看圖

最小範例

func run(in io.Reader, out io.Writer) error {
	sc := bufio.NewScanner(in)
	sum := 0
	for sc.Scan() {
		n, err := strconv.Atoi(sc.Text())
		if err != nil {
			return err
		}
		sum += n
	}
	fmt.Fprintf(out, "總和 %d\n", sum)
	return sc.Err()
}

func main() {
	err := run(strings.NewReader("3\n4\n5\n"), os.Stdout)
	fmt.Println("err:", err)
}

輸出

總和 12
err: <nil>

工程師筆記

  • 函式收 io.Reader / io.Writer，不要直接用 os.Stdin / os.Stdout：測試時就能餵字串進去，把結果收進 strings.Builder。
  • Scan() 回傳 false 之後要檢查 sc.Err()，才知道是讀完了還是出錯。
  • bufio.Scanner 預設一行最多 64KB，超過要用 sc.Buffer 調大。
  • 提示訊息寫到 os.Stderr，os.Stdout 只放結果，接 pipe 時比較乾淨。
  • 常用動詞：%v 預設格式、%+v 加上欄位名、%#v Go 語法、%T 型別、%q 加引號。
  • 命令列參數在 os.Args，os.Args[0] 是程式本身；要解析參數用標準庫的 flag。
