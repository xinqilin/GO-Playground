核心程式

func Recursive(n int) int {
	if n <= 0 {
		return 0
	}
	if n == 1 {
		return 1
	}
	return Recursive(n-1) + Recursive(n-2)
}

func Iterative(n int) int {
	a, b := 0, 1
	for range max(n, 0) {
		a, b = b, a+b
	}
	return a
}

工程師筆記

  • 遞迴先寫停止條件，而且要涵蓋所有可能的輸入，包括 0 和負數；測試表格裡也要放這些邊界值。
  • 舊版的 rand.Seed(time.Now().UnixNano()) 不用再寫：Go 1.20 起 math/rand 會自動用隨機種子，新程式建議直接用 math/rand/v2。
  • 64 位元的 int 最多放得下 F(92)；再大就會溢位，要改用 math/big。
  • 把參數解析和輸出放進 run(args, out)，main 只負責接上 os.Args 和 os.Stdout，測試就能直接呼叫 run。
  • 同樣算 F(25)，遞迴比迭代慢了三萬倍以上。先找對演算法，再談最佳化。
