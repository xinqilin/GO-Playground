工具鏈

go 指令是一整箱工具：排版、檢查、文件、測試、編譯都在裡面，不用另外安裝。

看圖

最小範例

edition_free.go 與 edition_pro.go

//go:build !pro

package main

const edition = "免費版"

// ---- edition_pro.go ----
//go:build pro

package main

const edition = "專業版"

main.go（節錄）

var version = "dev" // 編譯時用 -ldflags 改掉

func describe() string {
	return fmt.Sprintf("版本 %s，%s", version, edition)
}

輸出

$ go run -tags pro ./chapters/24-toolchain
版本 dev，專業版
平台 darwin/arm64
$ go run -ldflags "-X main.version=1.2.3" ./chapters/24-toolchain
版本 1.2.3，免費版
平台 darwin/arm64

工程師筆記

  • gofmt -l .、go vet ./...、go test -race ./... 是提交前的基本三件事，這個 repo 的 CI 也是跑這三個。
  • go fix -diff ./... 會列出可以換成新寫法的地方（例如三段式迴圈改成 range 3、errors.As 改成 errors.AsType）。這個 repo 有幾處刻意保留舊寫法做對照，所以會被列出來。
  • build tag 寫在檔案第一行：//go:build pro，用 -tags pro 切換；檔名結尾是 _windows.go、_linux.go 的檔案會自動依平台挑選。
  • -ldflags "-X main.version=1.2.3" 在編譯時寫入版本號，CI 發版時很常用。
  • 交叉編譯只要設 GOOS、GOARCH；只有用到 cgo 的程式才會麻煩。
  • 效能分析：go test -cpuprofile cpu.out 產生 profile，再用 go tool pprof cpu.out 找熱點；服務可以匯入 net/http/pprof 線上查看。依賴的已知漏洞用 govulncheck 掃描（另外安裝）。
