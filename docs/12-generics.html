泛型

泛型是一個模具：形狀先刻好，要用時才決定倒進去的是 int 還是 string。

看圖

最小範例

func Map[T, U any](s []T, f func(T) U) []U {
	out := make([]U, 0, len(s))
	for _, v := range s {
		out = append(out, f(v))
	}
	return out
}

type Stack[T any] struct{ items []T }

func (s *Stack[T]) Push(v T) { s.items = append(s.items, v) }

func main() {
	fmt.Println(Map([]int{1, 2, 3}, strconv.Itoa))
	var s Stack[string]
	s.Push("Go")
	fmt.Println(s.items, max(3, 7)) // max 是 Go 1.21 起的內建函式
}

輸出

[1 2 3]
[Go] 7

工程師筆記

  • 先寫具體型別，同樣的邏輯出現第二、三次再改成泛型。如果只是「呼叫某個方法」，interface 通常更簡單。
  • 常用限制：any、comparable（可以用 ==，能當 map key）、cmp.Ordered（可以用 <）。
  • ~T 代表「底層型別是 T」。加了 ~，自訂型別（像 type Celsius float64）才能用。
  • 大多數時候型別參數會自動推斷，不用寫成 Sum[int](…)。
  • 先找標準庫：Go 1.21 起有內建的 min、max、clear，slices、maps 套件也提供大量泛型函式。
  • Go 1.27 起方法可以有自己的型別參數；但介面的方法不能有型別參數，generic method 也不能拿來實作介面。
