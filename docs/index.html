Go 圖解手冊

給想學 Go 的人：每一章先用圖講懂觀念，再一步一步看可以執行、有測試的程式，最後用有自動測試的練習確認自己真的會了。會 Java 的話，每章都有對照。

會其他程式語言：從第 00 章開始 →從來沒寫過程式：從先修開始 →

每一章怎麼讀

每一章都是一篇長文，照同樣的順序排列。第一次讀可以先看圖、說明和輸出，程式碼的細節和「深入」留到第二次。

  • 本章內容、本章你會學到：先知道這一章要解決什麼問題；需要先讀哪幾章，這裡有連結。
  • 編號的小節：一節一個主題，先看圖，再看說明、程式碼和實際的輸出。頁面上的程式碼和輸出都由工具從 repo 裡有測試的程式產生，CI 會檢查兩邊一致，書上的程式一定跑得出書上的結果。
  • 深入：標著「深入：第一次讀可以先跳過」的虛線框，講原理和少見的情況。
  • 常見錯誤：錯誤和正確的寫法並排，說明為什麼錯。編譯不過的例子附上真的編譯錯誤訊息，在自己的電腦上看到時就認得出來。
  • 從 Java 來的你：同一件事在 Java 和 Go 的寫法對照。先修和沒有好對照的章節沒有這一段。
  • 練習、重點回顧、延伸閱讀：練習有自動測試（見下一段）；重點回顧是一份檢查清單；延伸閱讀只連到官方的語言規格、套件文件和 Go 部落格。

專題的頁面則是走讀一個完整的程式：從需求、設計到測試，最後是沒有附測試的延伸挑戰，讓你自己動手改。

練習怎麼做

每一章都有 5 到 7 題練習，全書共 245 題，題目在 exercises/章節目錄/exercises.go（28 章是獨立的 module，在 chapters/28-database/exercises/）。函式的名字和參數已經寫好；除了 00 章和先修 1 的 4 題「動手做」要在自己的電腦上操作，其餘 241 題都有測試，一開始全部失敗，寫對一題就通過一題。

go test ./exercises/03-control-flow/                       # 跑這一章的全部練習
go test ./exercises/03-control-flow/ -run TestTicketPrice  # 只跑一題
go test -tags solution ./exercises/03-control-flow/        # 跑參考解答
  • 難度：分成入門、進階、挑戰；另外還有「找錯」，程式已經寫好但有 bug，要找出來修好。
  • 卡住的時候：頁面上每一題都有可以點開的提示。還是寫不出來，再看同一個目錄的 solution.go；自己先寫過一次，對照解答時才看得出差在哪裡。
  • 測試就是規格：exercises_test.go 裡的每一個測試案例都是題目的一部分，題目看不懂時，讀測試最準。
  • 在根目錄跑 go test ./... 會失敗：因為練習還沒寫完，這是預期的。只想確認範例程式，用 go test ./chapters/... ./projects/...。
  • 專題：沒有附測試的練習，而是延伸挑戰：先寫測試描述你要的行為，再改程式。

在自己的電腦上跑

需要 Go 1.21 以上；go.mod 宣告的是 go 1.27，比較舊的 Go 會自動下載需要的版本。

git clone https://github.com/xinqilin/GO-Playground.git
cd GO-Playground
go run ./chapters/00-hello                  # 執行某一章
go test ./chapters/... ./projects/...       # 跑章節和專題的測試
go test ./exercises/03-control-flow/        # 做練習（寫完之前會失敗）
