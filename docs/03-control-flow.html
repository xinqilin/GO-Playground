流程控制

Go 只有 if、for、switch 三種路標，沒有 while，也沒有三元運算子。

看圖

最小範例

func main() {
	if n, err := strconv.Atoi("42"); err == nil {
		fmt.Println("兩倍是", n*2)
	}
	for i := range 3 {
		fmt.Print(i)
	}
	fmt.Println()
	switch day := "六"; day {
	case "六", "日":
		fmt.Println("週末")
	default:
		fmt.Println("平日")
	}
}

輸出

兩倍是 84
012
週末

工程師筆記

  • 條件不加括號，但大括號一定要寫，而且 { 要跟條件在同一行。
  • 沒有 while、do-while，全部用 for；也沒有三元運算子，寫成 if/else。
  • Go 1.22 起，迴圈變數每一圈都是新的一份，在 closure 或 goroutine 裡用到迴圈變數不會再全部拿到最後一個值。
  • switch 的 case 不用寫 break；case 可以是任何運算式，也可以列多個值。
  • fallthrough 不檢查下一個 case 的條件就直接執行，實務上很少用。
  • break、continue 加標籤可以作用在外層迴圈。
