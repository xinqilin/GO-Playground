HTTP 服務

HTTP server 像一間餐廳：路由是帶位的服務生，handler 是廚師，middleware 是門口的登記簿。

看圖

最小範例

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /hello/{name}", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintf(w, "哈囉，%s\n", r.PathValue("name"))
	})
	srv := &http.Server{
		Addr:              ":8080",
		Handler:           mux,
		ReadHeaderTimeout: 5 * time.Second,
	}
	log.Fatal(srv.ListenAndServe())
}

另一個終端機

$ curl localhost:8080/hello/Gopher
哈囉，Gopher

工程師筆記

  • Go 1.22 起 ServeMux 支援方法和路徑變數："GET /notes/{id}"，用 r.PathValue("id") 取值；方法不對會自動回 405。
  • handler 會被很多 goroutine 同時呼叫，共用的資料要加鎖。
  • http.Server 一定要設逾時（至少 ReadHeaderTimeout）；直接呼叫 http.ListenAndServe 沒有任何逾時。
  • middleware 就是「收一個 http.Handler、回傳一個 http.Handler」的函式，可以一層一層包起來。
  • HTTP client 也要設逾時：&http.Client{Timeout: 10 * time.Second}；預設的 http.DefaultClient 沒有逾時。
  • 關機時呼叫 srv.Shutdown(ctx)，等進行中的請求做完再結束；專題 todoapi 有完整示範。
