第一支程式

原始碼是食譜，編譯器是廚師，執行檔是做好的菜。

看圖

最小範例

package main

import "fmt"

func main() {
	fmt.Println("Hello, 世界")
	fmt.Println("整數", 3, "小數", 3.14, "布林", true)
	fmt.Println('a', '世')
}

輸出

Hello, 世界
整數 3 小數 3.14 布林 true
97 19990

工程師筆記

  • 安裝：macOS 用 brew install go，其他平台到 go.dev/dl 下載，裝好後用 go version 確認。
  • 這個 repo 的 go.mod 寫的是 go 1.27。本機只要有 Go 1.21 以上，go 指令就會自動下載需要的版本（GOTOOLCHAIN=auto）。
  • go run 每次都會編譯，但有 build cache，所以很快。部署用 go build 產生的單一執行檔，目標機器不用裝 Go。
  • 沒用到的 import 或區域變數是編譯錯誤，不是警告。
  • 格式只有一種：gofmt，縮排用 tab。大部分編輯器存檔時會自動執行。
  • 名稱大寫開頭，才能被其他 package 使用（第 20 章）。

動手跑

在這個 repo 裡

git clone https://github.com/xinqilin/GO-Playground.git
cd GO-Playground
go run ./chapters/00-hello
go test ./chapters/00-hello
go build -o bin/hello ./chapters/00-hello   # 產生執行檔
./bin/hello

自己從零建一個

mkdir hello && cd hello
go mod init example.com/hello
# 把上面的程式存成 main.go
go run .
