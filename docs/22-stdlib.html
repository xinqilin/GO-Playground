標準庫精選

標準庫是一個隨附的工具箱：時間、JSON、檔案、log、UUID 都有，大部分工作不用裝第三方套件。

看圖

最小範例

type User struct {
	Name string `json:"name"`
	Age  *int   `json:"age,omitempty"`
}

func main() {
	t := time.Date(2026, time.October, 9, 14, 30, 0, 0, time.UTC)
	fmt.Println(t.Format("2006-01-02 15:04")) // 用參考時間當範本

	b, err := json.Marshal(User{Name: "小明", Age: new(30)})
	fmt.Println(string(b), err)
}

輸出

2026-10-09 14:30
{"name":"小明","age":30} <nil>

工程師筆記

  • 常用的時間格式已經定義好：time.RFC3339、time.DateTime、time.DateOnly。時間計算用 time.Duration（90 * time.Minute），存資料庫和傳 API 盡量用 UTC。
  • JSON 欄位要匯出才會被編碼。區分「沒有值」和「零值」，用指標或 omitzero（Go 1.24）。
  • Go 1.27 起 encoding/json 改用 v2 的實作，v1 的 API 不變，但錯誤訊息的文字可能不同，程式不要比對錯誤字串。
  • log/slog 是標準的結構化 log；正式環境用 slog.NewJSONHandler，交給 log 平台搜尋。
  • uuid 是 Go 1.27 新加入的套件：uuid.New() 目前等同 v4；需要依時間排序（例如資料庫主鍵）就用 uuid.NewV7()。
  • 小檔案直接 os.ReadFile / os.WriteFile；大檔案用 os.Open 搭配 bufio.Scanner 一行一行讀。
