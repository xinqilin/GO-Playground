interface

interface 是一張「會做什麼」的清單：方法對上了就符合，不用先報名。

看圖

最小範例

type Shape interface{ Area() float64 }

type Rect struct{ W, H float64 }
type Circle struct{ R float64 }

func (r Rect) Area() float64   { return r.W * r.H }
func (c Circle) Area() float64 { return math.Pi * c.R * c.R }

func main() {
	for _, s := range []Shape{Rect{3, 4}, Circle{1}} {
		fmt.Printf("%T %.2f\n", s, s.Area())
	}
	var v any = Rect{1, 2}
	if r, ok := v.(Rect); ok {
		fmt.Println("寬", r.W)
	}
}

輸出

main.Rect 12.00
main.Circle 3.14
寬 1

工程師筆記

  • interface 越小越好。標準庫最常用的 io.Reader、io.Writer、fmt.Stringer、error 都只有一個方法。
  • 慣例是「參數收 interface、回傳具體型別」；interface 由使用的那一方定義，真的需要時再抽出來。
  • var _ Shape = Rect{} 讓編譯器幫你確認型別有實作介面。
  • 不帶 ok 的 v.(Rect)，型別不符會 panic；不確定時用 r, ok := v.(Rect)。
  • 函式回傳 error 時，沒錯就直接 return nil，不要回傳一個值是 nil 的具體型別指標，否則呼叫端的 err != nil 會成立。
  • 方法是 pointer receiver 時，只有指標符合介面：要放 &T{} 進去，放 T{} 會編譯錯誤。
