map

map 是一排有名牌的置物櫃：報上名字，就直接打開那一格。

看圖

最小範例

func main() {
	stock := map[string]int{"蘋果": 0}
	n, ok := stock["芒果"] // 不存在：拿到零值和 false
	fmt.Println(n, ok)

	counts := map[string]int{}
	for _, w := range strings.Fields("go is go") {
		counts[w]++
	}
	for _, k := range slices.Sorted(maps.Keys(counts)) {
		fmt.Println(k, counts[k])
	}
}

輸出

0 false
go 2
is 1

工程師筆記

  • map 要用 make 或字面值建立；只宣告的 nil map 可以讀，寫入會 panic：assignment to entry in nil map。
  • 讀不存在的 key 拿到零值，所以 counts[w]++ 不用先檢查 key 在不在。
  • 走訪順序不固定，而且是刻意的；要固定順序就 slices.Sorted(maps.Keys(m))。
  • key 必須能用 == 比較：slice、map、func 不能當 key；欄位都能比較的 struct 可以。
  • map 不能同時被多個 goroutine 寫入，會直接 fatal error: concurrent map writes，要加 sync.Mutex（第 17 章）。
  • map 裡的值不能取地址：m[k].Field = 1 編譯不過，要整個取出、修改、再放回去。要做 set 就用 map[string]struct{}。
