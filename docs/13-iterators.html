疊代器

疊代器是一台發球機：你要一顆，它丟一顆；你喊停，它就停。

看圖

最小範例

func Countdown(n int) iter.Seq[int] {
	return func(yield func(int) bool) {
		for i := n; i >= 1; i-- {
			if !yield(i) {
				return
			}
		}
	}
}

func main() {
	for n := range Countdown(5) {
		if n == 2 {
			break // 這時 yield 回傳 false
		}
		fmt.Println(n)
	}
	fmt.Println(slices.Collect(Countdown(3)))
}

輸出

5
4
3
[3 2 1]

工程師筆記

  • iter.Seq[V] 就是 func(yield func(V) bool)；iter.Seq2[K, V] 一次交出兩個值，像 slices.All 交出 index 和值。
  • 一定要檢查 yield 的回傳值。使用端 break 之後還繼續 yield，會 panic：range function continued iteration after function for loop body returned false。
  • 疊代器是惰性的：沒有 range 就不會執行，所以可以表示無限長的序列。
  • 標準庫：slices.All、slices.Values、slices.Collect、slices.Sorted、maps.Keys、maps.Values（Go 1.23），strings.SplitSeq、strings.Lines（Go 1.24）。
  • 想用「呼叫 next() 拿下一個」的方式，用 iter.Pull，用完記得呼叫 stop。
  • 一般的 slice 直接 range 就好；需要組合、惰性，或想隱藏內部資料結構時，才自己寫疊代器。
