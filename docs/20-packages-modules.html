package 與 module

module 是一整棟大樓，package 是裡面的房間；門牌就是 import 路徑。

最小範例

greet/greet.go（節錄）

package greet

var Prefix = "哈囉"

func Hello(name string) string { // 大寫開頭：其他套件可以用
	return Prefix + "，" + normalize(name)
}

func normalize(name string) string { … } // 小寫開頭：只有 greet 自己能用

main.go（節錄）

import (
	"github.com/xinqilin/GO-Playground/chapters/20-packages-modules/greet"
	"github.com/xinqilin/GO-Playground/chapters/20-packages-modules/internal/counter"
)

func init() { fmt.Println("init：在 main 之前執行") }

func main() {
	fmt.Println(greet.Hello("Gopher"))
	fmt.Println(greet.Hello("  "))
	greet.Prefix = "嗨"
	fmt.Println(greet.Hello("Go"))
	fmt.Println(counter.Next(), counter.Next())
}

工程師筆記

  • 一個資料夾就是一個 package，裡面的檔案 package 名稱要一樣；package 名稱通常就是資料夾的最後一段。
  • internal/ 底下的 package 只有它的上一層目錄樹能 import，用來藏實作細節。
  • go get 新增依賴、go mod tidy 整理 go.mod 和 go.sum；go.sum 記錄依賴的校驗碼，要一起 commit。
  • 不能循環 import：A import 了 B，B 就不能再 import A。遇到了通常代表要再切出一個 package。
  • package 名稱短、小寫、不加底線；避免 util、common 這種什麼都放的名字。
  • init() 會在 main 之前自動執行。用多了會讓啟動順序難以追蹤，能不用就不用。
