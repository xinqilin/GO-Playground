函式

函式是一台機器：放進參數，拿出結果；機器本身也能拿來傳來傳去。

看圖

最小範例

func divmod(a, b int) (int, int) { return a / b, a % b }

func counter() func() int {
	n := 0
	return func() int { n++; return n }
}

func main() {
	defer fmt.Println("最後才執行")
	q, r := divmod(17, 5)
	next := counter()
	fmt.Println(q, r, next(), next(), next())
}

輸出

3 2 1 2 3
最後才執行

工程師筆記

  • 錯誤用回傳值傳遞：慣例是最後一個回傳值放 error，呼叫端馬上檢查（第 11 章）。
  • defer 最常用在釋放資源：os.Open 成功後馬上 defer f.Close()，之後不管從哪裡 return 都會關檔。
  • defer 的參數在註冊當下就決定；在迴圈裡 defer 要小心，要等整個函式結束才會執行。
  • 回傳值可以取名（func f() (n int, err error)）。短函式可以搭配不帶值的 return，長函式這樣寫會很難讀。
  • 整數除法往 0 截斷：-7 / 2 是 -3，-7 % 2 是 -1。
  • 沒有預設參數，也沒有函式多載；選項多時改用 struct 當參數。
