select

select 是同時盯著好幾個窗口的櫃檯：哪一個先有人，就先處理哪一個。

看圖

最小範例

func main() {
	slow := make(chan string) // 永遠不會有人送
	select {
	case v := <-slow:
		fmt.Println(v)
	case <-time.After(50 * time.Millisecond):
		fmt.Println("逾時")
	}

	ready := make(chan int, 1)
	select {
	case v := <-ready:
		fmt.Println(v)
	default:
		fmt.Println("現在沒有，先做別的")
	}
}

輸出

逾時
現在沒有，先做別的

工程師筆記

  • 好幾個 case 同時準備好時，select 隨機挑一個，不是由上往下。
  • time.After 每次呼叫都建一個新的計時器。Go 1.23 起沒人用的計時器會被回收，在迴圈裡用也不會洩漏；熱點迴圈改用 time.NewTimer 搭配 Reset 比較省。
  • default 讓 select 不阻塞；但在迴圈裡只有 default 沒有任何等待，會變成空轉吃滿 CPU。
  • 把 channel 變數設成 nil 可以停用某個 case：從 nil channel 收會永遠卡住，select 就不會選它。
  • 需要等待時，通常同時盯著 ctx.Done()，上層取消時才能馬上離開（第 18 章）。
