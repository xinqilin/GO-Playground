字串與 rune

字串是一排封好的 byte，不能拆開改。英文字一個 byte 就裝得下，中文字要用三個 byte 才裝得下一個字。

1. 字串的基本操作

func stringBasics() {
	s := "Hello, Go"
	fmt.Println(len(s), s[0], string(s[0])) // 索引拿到的是 byte
	fmt.Println(s[7:], s[:5])               // 切片的結果還是字串
	greeting := s[:5] + "，便當店"
	fmt.Println(greeting)
	fmt.Println("排骨" == "排骨", "apple" < "banana", "Zoo" < "apple")
}

輸出

9 72 H
Go Hello
Hello，便當店
true true true
  • len(s) 是 byte 的個數，不是字數（第 2 節）。
  • s[i] 拿到的是一個 byte（也就是 uint8），所以印出來是 72，不是 H。要看成字元得轉換：string(s[0])。
  • s[low:high] 和 slice 一樣，結果還是字串，而且和原本的字串共用同一塊記憶體，不會複製。
  • + 串接、== 比較內容、< 依照 byte 逐個比較。大寫字母的編碼比小寫小，所以 "Zoo" < "apple"。

字串不能修改

package main

import "fmt"

func main() {
	s := "Go語言"
	s[0] = 'g'
	fmt.Println(s)
}

編譯錯誤

./main.go:7:2: cannot assign to s[0] (neither addressable nor a map index expression)

字串一旦建立就不能修改（immutable）。s = "go語言" 是讓 s 指向另一個字串，原本的字串沒有變。不能修改的好處是字串可以安全地共用：切片不必複製、傳給函式不必複製、多個 goroutine 同時讀也沒問題。要「修改」字串，就轉成 []byte 或 []rune 改完再轉回來（第 4 節），或用 strings 套件產生新的字串（第 5 節）。

兩種字串字面值

func literals() {

	query := `SELECT name, price

	fmt.Println(query)

輸出

第一行
第二行
價格	85
C:\menu\new.txt

WHERE price < 100

雙引號的字串會處理跳脫字元：\n 換行、\t tab、\" 雙引號、\\ 反斜線、語 用碼位寫一個字。反引號的字串（raw string）照原樣保留每個字元，反斜線就是反斜線，也可以直接跨行，適合 Windows 路徑、正規表示式、SQL、JSON 範本。反引號字串裡唯一不能出現的是反引號本身。

2. UTF-8：byte 與 rune

電腦只認得數字。Unicode 替世界上每個字元編了一個號碼，叫做碼位（code point）：G 是 U+0047，「語」是 U+8A9E。UTF-8 則規定怎麼把碼位存成 byte：英文字母和數字用 1 個 byte，常用的中文字用 3 個 byte，有些罕用字和符號用 4 個。Go 的原始碼規定用 UTF-8 存，字串字面值自然也是 UTF-8。

func bytesVsRunes() {
	s := "Go語言"
	fmt.Println(len(s), utf8.RuneCountInString(s))
	fmt.Println(s[0], s[2]) // 71 是 'G'；232 只是「語」的第一個 byte
	fmt.Printf("% x\n", s)  // 每個 byte 用十六進位印出來
}

輸出

8 4
71 232
47 6f e8 aa 9e e8 a8 80

% x 把每個 byte 用十六進位印出，中間用空白隔開，對照上圖就是 47 6f（G、o）和兩組 3 個 byte（語、言）。要知道有幾個「字」，用 utf8.RuneCountInString，它要從頭走一遍字串才算得出來，不像 len 是直接讀出來的。

rune

func runeLiteral() {
	r := '語'
	fmt.Println(r)
	fmt.Printf("%c %U %T\n", r, r, r)
	fmt.Println(utf8.RuneLen(r), utf8.RuneLen('G'))
	fmt.Println(string(r) + "言")
}

輸出

35486
語 U+8A9E int32
3 1
語言

單引號寫的是 rune 字面值，代表一個碼位。rune 是 int32 的別名，所以直接印出來是數字 35486（也就是 0x8A9E），%T 印出 int32。要印成字元用 %c，印成 U+ 的寫法用 %U。utf8.RuneLen 告訴你一個 rune 編成 UTF-8 要幾個 byte。注意單引號和雙引號不同：'語' 是一個 rune，"語" 是一個 3 byte 的字串。

把字切壞

func cutInMiddle() {
	s := "Go語言"
	fmt.Printf("%q %v\n", s[:3], utf8.ValidString(s[:3]))
	fmt.Printf("%q %v\n", s[:5], utf8.ValidString(s[:5]))
}

輸出

"Go\xe8" false
"Go語" true

切片運算式用的是 byte 位置。s[:3] 只拿到「語」3 個 byte 中的第一個，結果是不合法的 UTF-8，%q 把那個 byte 印成 \xe8，印到終端機上就是亂碼。Go 的字串可以裝任何 byte，不保證內容是合法的 UTF-8；從檔案或網路讀進來的資料，需要時用 utf8.ValidString 檢查。依照「字數」截斷字串要先轉成 []rune，練習 4 就是這個 bug。

3. range 字串

func rangeString() {
	for i, r := range "Go語言" {
		fmt.Println(i, string(r), r)
	}
}

輸出

0 G 71
1 o 111
2 語 35486
5 言 35328

for i, r := range s 會依照 UTF-8 解碼，每一圈拿到一個完整的 rune。i 是這個字開始的 byte 位置，不是第幾個字，所以 i 從 2 跳到 5：「語」佔了 2、3、4 三個 byte。要處理「字」的程式，例如計算中文字數、找出某種字元，都應該用 range，而不是用索引一個 byte 一個 byte 走（第 03 章的 range）。

不合法的 byte

func rangeInvalid() {
	for i, r := range "A\xffB" {
		fmt.Printf("%d %U\n", i, r)
	}
}

輸出

0 U+0041
1 U+FFFD
2 U+0042

\xff 不是任何字元合法的 UTF-8 開頭。range 遇到這種 byte 不會 panic，而是拿到 U+FFFD（替代字元，通常顯示成一個問號方塊），並且只前進 1 個 byte，接著繼續解碼。所以 range 一定走得完，但結果可能含有 U+FFFD，代表原始資料有問題。

4. 轉換

func conversions() {
	s := "Go語言"
	b := []byte(s)
	r := []rune(s)
	fmt.Println(len(b), len(r))
	fmt.Println(b[:2], r[2:])
	fmt.Println(string(r[2]), string(r[2:]))
	b[0] = 'g' // 改的是複本
	fmt.Println(s, string(b))
}

輸出

8 4
[71 111] [35486 35328]
語 語言
Go語言 go語言
  • []byte(s)：複製出一份可以修改的 byte。改了 b[0]，s 還是原樣。處理二進位資料、檔案內容、網路封包時常用。
  • []rune(s)：解碼成一個一個字。長度就是字數，可以用索引拿「第幾個字」。代價是每個字佔 4 byte，中文字串轉換後大約變成 1.3 倍大，英文字串則變成 4 倍。
  • string(b)、string(r)：轉回字串，同樣會複製。string(r[2]) 把單一個 rune 轉成字串。

因為字串不能改，修改「第幾個字」的標準寫法就是轉成 []rune、改、轉回來：

func replaceAt(s string, i int, c rune) string {
	r := []rune(s)
	r[i] = c
	return string(r)
}

func editRunes() {
	fmt.Println(replaceAt("大杯紅茶", 0, '中'))
}

輸出

中杯紅茶

數字轉字串

func numberToString() {
	n := 65
	fmt.Println(strconv.Itoa(n), string(rune(n)))
	fmt.Println(fmt.Sprint(n) + "元")
}

輸出

65 A
65元

把數字 65 變成字串 "65" 要用 strconv.Itoa 或 fmt.Sprint。string(rune(65)) 是另一件事：把 65 當成碼位，得到字元 A。直接寫 string(n)（n 是 int）在語法上是合法的，意思也是後者，所以幾乎一定是 bug，go vet 會攔下來：

package main

import "fmt"

func main() {
	n := 85
	price := string(n) + "元"
	fmt.Println(price)
}

go vet

main.go:7:11: conversion from int to string yields a string of one rune, not a string of digits

這支程式能編譯，執行結果是字元 U+0055（大寫 U）接上「元」，不是「85元」。

4.1 轉換的成本與編譯器的最佳化

字串在內部和 slice 很像，是一個只有 ptr 和 len 兩個欄位的 header（沒有 cap，因為不能 append）。[]byte(s) 必須複製，因為 slice 可以修改，而字串不行；如果共用同一塊記憶體，改 slice 就等於改了字串。

不過編譯器會在確定安全的地方省掉複製，例如：用 m[string(b)] 查 map、string(b) == "OK" 比較、for i, c := range []byte(s) 走訪。這些情況下轉換出來的值不會被保存或修改，就不需要真的配置。這是實作的最佳化，不是規格保證，寫程式時不必刻意依賴。

另外，s[low:high] 和原本的字串共用記憶體，所以從一個很大的字串（例如整個檔案的內容）切出一小段長期保存，會讓整個大字串無法回收，和第 06 章的小 slice 拖住大陣列一樣。需要時用 strings.Clone 複製出來。

5. strings 套件

處理字串的函式大多在 strings 套件。它們都不會修改傳進去的字串，而是回傳新的結果。下面依用途分成四組。

搜尋

func searchFuncs() {
	addr := "台北市大安區便當路 100 號"
	fmt.Println(strings.Contains(addr, "大安區"), strings.HasPrefix(addr, "台北市"), strings.HasSuffix(addr, "號"))
	fmt.Println(strings.Index(addr, "大安"), strings.Index(addr, "信義"))
	fmt.Println(strings.Count("排骨,雞腿,排骨", "排骨"))
	fmt.Println(strings.EqualFold("Go", "GO"))
}

輸出

true true true
9 -1
2
true

Index 回傳的是 byte 位置：「台北市」是 9 個 byte，所以「大安」從 9 開始；找不到時回傳 -1。拿這個位置去切片 addr[9:] 是安全的，因為它一定落在字的開頭。EqualFold 比較時忽略大小寫，比 ToLower(a) == ToLower(b) 有效率。

切開與接起來

func splitJoin() {
	fmt.Printf("%q\n", strings.Split("排骨,雞腿,,素食", ","))
	fmt.Printf("%q\n", strings.Fields("  排骨  雞腿\t素食\n"))
	fmt.Println(strings.Join([]string{"排骨", "雞腿", "素食"}, "、"))
}

輸出

["排骨" "雞腿" "" "素食"]
["排骨" "雞腿" "素食"]
排骨、雞腿、素食

Split 依照分隔字串切開，兩個逗號之間會得到一個空字串，不會被略過。Fields 依照任意長度的空白（空格、tab、換行）切開，並且忽略頭尾的空白，處理使用者輸入時通常比 Split 好用。Join 把一個字串 slice 用分隔字串接起來，是 Split 的反向操作。

去頭尾與切成兩半

func trimCut() {
	fmt.Printf("%q\n", strings.TrimSpace("  排骨飯 \n"))
	fmt.Println(strings.TrimPrefix("INV-AB12345678", "INV-"), strings.TrimSuffix("menu.txt", ".txt"))
	fmt.Println(strings.Trim("**特價**", "*"))
	name, qty, ok := strings.Cut("排骨x2", "x")
	fmt.Println(name, qty, ok)
	_, _, ok = strings.Cut("排骨", "x")
	fmt.Println(ok)
}

輸出

"排骨飯"
AB12345678 menu
特價
排骨 2 true
false
  • TrimSpace：去掉頭尾的空白和換行，讀進來的每一行幾乎都要先做這一步。
  • TrimPrefix、TrimSuffix：去掉一個完整的前綴或後綴，沒有就原樣回傳。
  • Trim(s, "*")：第二個參數是一組字元，頭尾只要是其中任何一個字元都會被去掉，不是去掉一個子字串。想去掉 "INV-" 這種固定前綴要用 TrimPrefix。
  • Cut：在第一個分隔字串的地方切成前後兩半，第三個回傳值表示有沒有找到。解析 key=value、品名x數量 這類格式時，比 Split 再檢查長度簡潔得多（練習 3）。

取代與轉換

func replaceFuncs() {
	fmt.Println(strings.ReplaceAll("0912-345-678", "-", ""))
	fmt.Println(strings.Replace("a-b-c", "-", "+", 1))
	fmt.Println(strings.Repeat("=", 10))
	fmt.Println(strings.ToUpper("go 語言"), strings.ToLower("HELLO"))
	r := strings.NewReplacer("台", "臺", "-", "")
	fmt.Println(r.Replace("台北-台中"))
}

輸出

0912345678
a+b-c
==========
GO 語言 hello
臺北臺中

Replace 的最後一個參數是最多取代幾次，-1 或用 ReplaceAll 表示全部。要同時做好幾組取代時用 strings.NewReplacer：它只掃描字串一次，而且建立一次之後可以重複使用。ToUpper 只影響有大小寫之分的字元，中文不受影響。

6. strings.Builder

func receipt(items []string, prices []int) string {
	var b strings.Builder
	total := 0
	for i, item := range items {
		fmt.Fprintf(&b, "%s %d\n", item, prices[i])
		total += prices[i]
	}
	b.WriteString("合計 ")
	b.WriteString(strconv.Itoa(total))
	return b.String()
}

func builderDemo() {
	fmt.Println(receipt([]string{"排骨", "雞腿"}, []int{85, 90}))
}

輸出

排骨 85
雞腿 90
合計 175

strings.Builder 內部是一個會自動長大的 []byte，WriteString、WriteByte、WriteRune 都往後面寫，最後 String() 一次轉成字串，而且不需要再複製。它實作了 io.Writer，所以可以直接當 fmt.Fprintf 的第一個參數（第 02 章的 Fprint 家族），格式化和組字串一次完成。零值就能直接使用，不需要初始化；但不要複製一個已經寫過內容的 Builder，要傳給函式時傳指標。

為什麼迴圈裡不要用 +

func concatPlus(parts []string) string {
	s := ""
	for _, p := range parts {
		s += p
	}
	return s
}

func concatBuilder(parts []string) string {
	n := 0
	for _, p := range parts {
		n += len(p)
	}
	var b strings.Builder
	b.Grow(n)
	for _, p := range parts {
		b.WriteString(p)
	}
	return b.String()
}

每次 s += p 都要配置一個新字串，把目前為止的內容整個複製過去，串接 n 次的總複製量會隨 n 的平方成長。本章的測試檔有兩個 benchmark（測試那一章會正式介紹），各把 1,000 段「便當」串起來：

go test -run='^$' -bench=Concat -benchmem ./chapters/08-strings-runes

輸出（節錄；數字依機器而不同）

BenchmarkConcatPlus-10       	    3402	    335814 ns/op	 3212610 B/op	     999 allocs/op
BenchmarkConcatBuilder-10    	  262716	      4530 ns/op	    6144 B/op	       1 allocs/op

用 + 配置了 999 次、總共約 3 MB；Builder 先用 Grow 保留好空間，只配置 1 次、6 KB，快了大約 70 倍。只串兩三段時用 + 最清楚，編譯器也會把同一個運算式裡的多個 + 合併成一次配置；在迴圈裡累積才需要 Builder。現成的 slice 要接起來，直接用 strings.Join。

7. strconv 與 unicode

字串轉數字

func parseNumbers() {
	n, err := strconv.Atoi("85")
	fmt.Println(n+5, err)
	_, err = strconv.Atoi("85元")
	fmt.Println(err)
	f, _ := strconv.ParseFloat("3.5", 64)
	fmt.Println(f * 2)
	big, err := strconv.ParseInt("99999999999", 10, 32)
	fmt.Println(big, err)
	h, _ := strconv.ParseInt("ff", 16, 64)
	ok, _ := strconv.ParseBool("true")
	fmt.Println(h, ok)
}

輸出

90 <nil>
strconv.Atoi: parsing "85元": invalid syntax
7
2147483647 strconv.ParseInt: parsing "99999999999": value out of range
255 true

使用者輸入、檔案內容、網址參數都是字串，要計算就得先轉成數字，而且一定要檢查錯誤。錯誤訊息會說明是哪個函式、哪個輸入、什麼問題：invalid syntax 是格式不對，value out of range 是超出指定的位元數。ParseInt(s, base, bitSize) 可以指定進位（16 進位的 ff 是 255）和結果要放得進幾個位元；超出範圍時會回傳該範圍的最大值和錯誤。Atoi 就是 ParseInt(s, 10, 0) 再轉成 int 的簡寫。

數字轉字串

func formatNumbers() {
	fmt.Println(strconv.Itoa(85) + "元")
	fmt.Println(strconv.FormatInt(255, 2), strconv.FormatInt(255, 16))
	fmt.Println(strconv.FormatFloat(3.14159, 'f', 2, 64))
	fmt.Println(strconv.Quote("排骨\n飯"), strconv.QuoteToASCII("排骨"))
}

輸出

85元
11111111 ff
3.14
"排骨\n飯" "\u6392\u9aa8"

FormatInt 可以轉成任何 2 到 36 進位，FormatFloat 的 'f', 2 表示固定小數點、保留兩位。Quote 加上雙引號並跳脫特殊字元，和 %q 的效果一樣；QuoteToASCII 連非 ASCII 的字也跳脫成 \u 的形式。fmt 也做得到這些轉換，但 strconv 不需要解析格式字串，比較快，也不會有格式和參數對不上的問題。

判斷字元的種類

func classify() {
	for _, r := range "A9語 ，" {
		fmt.Printf("%q 字母=%v 數字=%v 漢字=%v 空白=%v 標點=%v\n",
			r, unicode.IsLetter(r), unicode.IsDigit(r), unicode.Is(unicode.Han, r), unicode.IsSpace(r), unicode.IsPunct(r))
	}
}

輸出

'A' 字母=true 數字=false 漢字=false 空白=false 標點=false
'9' 字母=false 數字=true 漢字=false 空白=false 標點=false
'語' 字母=true 數字=false 漢字=true 空白=false 標點=false
' ' 字母=false 數字=false 漢字=false 空白=true 標點=false
'，' 字母=false 數字=false 漢字=false 空白=false 標點=true

unicode 套件依照 Unicode 的分類判斷 rune：中文字是字母（Letter），unicode.Is(unicode.Han, r) 進一步判斷是不是漢字；全形逗號是標點。這些函式接收的是 rune，所以要搭配 range 使用。

全形轉半形

func toHalfwidth(s string) string {
	return strings.Map(func(r rune) rune {
		switch {
		case r >= '！' && r <= '～':
			return r - 0xFEE0
		case r == '　': // 全形空白
			return ' '
		}
		return r
	}, s)
}

func halfwidth() {
	fmt.Println(toHalfwidth("ＡＢ－１２３４５６７８"))
}

輸出

AB-12345678

表單裡常有人用全形輸入英數字，例如發票號碼「ＡＢ－１２３４５６７８」。全形的「！」到「～」和半形的 ! 到 ~ 依序一一對應，碼位剛好差 0xFEE0，所以減掉這個數就能轉回半形。strings.Map 對字串的每個 rune 呼叫你給的函式，用回傳的 rune 組成新字串，適合這種逐字轉換。

8. 中文的顯示寬度

第 02 章看過：%-8s 依照「字數」補空白，但中文字在終端機上佔兩格，所以含中文的表格會對不齊。解法是自己算每個字佔幾格，再補上剛好的空白：

func runeWidth(r rune) int {
	switch {
	case unicode.Is(unicode.Han, r),
		unicode.In(r, unicode.Hiragana, unicode.Katakana, unicode.Hangul),
		r >= 0x3000 && r <= 0x303F, // 中日韓的標點，例如「、」「。」「「」
		r >= 0xFF01 && r <= 0xFF60, // 全形的英數字和標點，例如「，」「！」
		r >= 0xFFE0 && r <= 0xFFE6: // 全形的貨幣符號等
		return 2
	}
	return 1
}

func displayWidth(s string) int {
	w := 0
	for _, r := range s {
		w += runeWidth(r)
	}
	return w
}

func padRight(s string, width int) string {
	if gap := width - displayWidth(s); gap > 0 {
		return s + strings.Repeat(" ", gap)
	}
	return s
}

func alignedMenu() {
	items := []string{"Coffee", "排骨飯", "雞腿便當"}
	for _, it := range items {
		fmt.Printf("|%-8s|\n", it)
	}
	for _, it := range items {
		fmt.Printf("|%s|\n", padRight(it, 8))
	}
}

輸出

|Coffee  |
|排骨飯     |
|雞腿便當    |
|Coffee  |
|排骨飯  |
|雞腿便當|

（網頁上的字型不一定是嚴格的等寬字型，對齊的效果要在終端機裡執行才看得準。）

  • runeWidth 把漢字、日文假名、韓文、中日韓標點和全形符號算 2 格，其他算 1 格。unicode.In 一次檢查好幾個 Unicode 區塊。
  • displayWidth 用 range 一個字一個字加總，padRight 用 strings.Repeat 補上差額。
  • 這是簡化版：Unicode 另外有一份「East Asian Width」的正式規則，還有組合字元（例如注音聲調）、emoji 等寬度是 0 或依終端機而定的情況。需要完整處理時，用標準庫以外的 golang.org/x/text/width。

常見錯誤

1. 用 len 算字數

len("排骨飯") 是 9，不是 3。限制「最多 10 個字」、顯示「已輸入 3 個字」時，用 utf8.RuneCountInString。

2. 用 byte 位置截斷中文

s[:n] 的 n 是 byte 位置，可能把中文字切成兩半，印出亂碼（第 2 節）。依字數截斷要先轉 []rune，或用 range 找到第 n 個字的 byte 位置再切。練習 4。

3. 用索引一個 byte 一個 byte 處理文字

for i := 0; i < len(s); i++ { s[i] … } 拿到的是 byte，處理中文一定出錯，例如判斷回文時把一個字的三個 byte 倒過來比。處理「字」用 range 或 []rune。練習 5。

4. 用 string(n) 把數字轉成字串

得到的是碼位 n 對應的字元，不是十進位數字。用 strconv.Itoa(n)，go vet 會幫你抓（第 4 節）。

5. 在迴圈裡用 + 累積字串

每一次都配置並複製整個字串，資料多時明顯變慢。改用 strings.Builder 或 strings.Join（第 6 節）。

6. 把 Trim 當成去掉子字串

strings.Trim("INV-NV1", "INV-") 會一直去掉頭尾屬於 I、N、V、- 這組字元的字，結果是 "1"，不是 "NV1"。去掉固定的前綴或後綴要用 TrimPrefix、TrimSuffix。

重點回顧

  • 字串是唯讀的 byte 序列，不能修改；切片和原本的字串共用記憶體。
  • len 是 byte 數，s[i] 是 byte；字數用 utf8.RuneCountInString。
  • UTF-8 裡英文 1 個 byte、常用中文 3 個 byte；用 byte 位置切字串可能把字切壞。
  • rune 是 int32，代表一個碼位；'語' 是 rune，"語" 是字串。
  • range 字串一次拿一個 rune，i 是 byte 位置；不合法的 byte 會變成 U+FFFD。
  • []byte(s)、[]rune(s)、string(…) 都會複製；改字串就是轉換、修改、再轉回來。
  • 數字轉字串用 strconv.Itoa，不要用 string(n)。
  • strings 套件：Contains、Index、Split、Fields、Join、TrimSpace、TrimPrefix、Cut、ReplaceAll、NewReplacer。
  • 迴圈裡累積字串用 strings.Builder，知道大小就先 Grow。
  • strconv 的 Parse 系列一定要檢查 error；unicode 判斷字元種類要搭配 range。
  • 中文在終端機佔兩格，對齊要依顯示寬度補空白，不能靠 %-Ns。
