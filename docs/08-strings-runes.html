字串與 rune

字串是一排唯讀的 byte；一個中文字要 3 個 byte 才裝得下。

看圖

最小範例

func main() {
	s := "Go語言"
	fmt.Println(len(s), utf8.RuneCountInString(s))
	fmt.Println(s[2]) // 一個 byte，不是「語」
	for i, r := range s {
		fmt.Println(i, string(r))
	}
	var b strings.Builder
	for range 3 {
		b.WriteString("Go")
	}
	fmt.Println(b.String())
}

輸出

8 4
232
0 G
1 o
2 語
5 言
GoGoGo

工程師筆記

  • len(s) 是 byte 數，不是字數；算字數用 utf8.RuneCountInString。
  • 字串不能修改，s[0] = 'g' 編譯不過；要改就轉成 []byte 或 []rune，改完再轉回來。這兩種轉換都會複製資料。
  • s[i:j] 用的是 byte 位置，切在中文字中間會得到亂碼。
  • string(rune(65)) 是 "A" 而不是 "65"；數字轉文字用 strconv.Itoa。直接寫 string(65) 時 go vet 會警告。
  • 字串可以直接用 ==、< 比較，比的是 byte。
  • 反引號字串不處理跳脫字元，還可以跨行，寫正規表示式、JSON、SQL 都很方便。
