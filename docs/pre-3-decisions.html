判斷與重複

到目前為止，程式都是從頭到尾一路直走。這一章讓它學會兩件事：遇到岔路時看條件選一條走，以及同一段路重複走很多圈，直到條件不再成立。

先備：先修 2 值、變數與運算（變數、= 與 ==、&& 與 ||、追蹤表）。

1. if 與 else：二選一

func passFail(score int) {
	if score >= 60 {
		fmt.Println(score, "分：及格")
	} else {
		fmt.Println(score, "分：不及格")
	}
}

func passFailDemo() {
	passFail(72)
	passFail(59)
	passFail(60)
}

輸出

72 分：及格
59 分：不及格
60 分：及格

if 後面接一個條件，也就是先修 2 學過、結果是 true 或 false 的比較。條件成立（true）就執行緊接著的大括號 { … }；不成立（false）就執行 else 後面的大括號。兩邊只會執行其中一邊，不會兩邊都做，也不會兩邊都不做。

這裡第一次出現帶參數的函式：passFail(72) 把 72 交給 passFail，函式裡的 score 就是 72。同一段判斷用三個不同的分數各跑一次，就看得到三種結果。函式的寫法在先修 4 會詳細介紹，現在只要知道括號裡的值會放進 score 就好。

60 分剛好及格，因為條件是 >=（大於或等於）。如果寫成 >，60 分就不及格了。測試條件時，一定要試剛好在邊界上的值。

只有 if，沒有 else

func umbrella(rain bool) {
	fmt.Println("準備出門")
	if rain {
		fmt.Println("帶傘")
	}
	fmt.Println("鎖門出發")
}

func umbrellaDemo() {
	umbrella(true)
	umbrella(false)
}

輸出

準備出門
帶傘
鎖門出發
準備出門
鎖門出發

else 可以不寫。條件不成立時，就跳過整個大括號，直接執行下一行。下雨時多做一件事（帶傘），不下雨就什麼都不多做。rain 本身就是 bool，所以可以直接當條件，不用寫成 rain == true。

大括號的位置是規定

Go 規定 { 要和 if 寫在同一行，else 要和前一個 } 寫在同一行，寫成 } else {。把 else 換到下一行會得到編譯錯誤（常見錯誤 6）。存檔時讓編輯器自動排版（gofmt），就不用記這些細節。

2. else if：多選一

func grade(score int) {
	level := ""
	if score >= 90 {
		level = "優"
	} else if score >= 80 {
		level = "甲"
	} else if score >= 70 {
		level = "乙"
	} else if score >= 60 {
		level = "丙"
	} else {
		level = "丁"
	}
	fmt.Println(score, level)
}

func gradeDemo() {
	grade(95)
	grade(83)
	grade(61)
	grade(40)
}

輸出

95 優
83 甲
61 丙
40 丁

83 分走到第二個條件 score >= 80 就成立了，於是 level 是「甲」，後面的 70、60 都不會再問。注意第二個條件只寫 score >= 80，不用寫 score >= 80 && score < 90：能走到這裡，就代表第一個條件已經不成立，分數一定小於 90。

level := "" 先建立一個空的變數，每個分支各自放進不同的值，最後統一印出。這是「依條件決定一個值」的常見寫法。

順序寫反會怎樣

func wrongGrade(score int) {
	level := ""
	if score >= 60 {
		level = "丙"
	} else if score >= 70 {
		level = "乙"
	} else if score >= 80 {
		level = "甲"
	} else if score >= 90 {
		level = "優"
	} else {
		level = "丁"
	}
	fmt.Println(score, level)
}

輸出

95 丙

95 分拿到「丙」。因為第一個問的是 score >= 60，95 分當然成立，於是就停在這裡，後面的條件根本沒機會被問到。這種程式能編譯、能執行、沒有任何錯誤訊息，只是答案錯了，正是先修 1 說的邏輯錯誤。規則是：範圍大的條件會蓋住範圍小的，所以要從最嚴格的條件（90 以上）問起。

3. 組合條件與決策樹

真實的規則常常好幾個條件交錯在一起。例如某個展覽的票價：「未滿 6 歲免費；未滿 12 歲或 65 歲以上半票 60 元；其他人是學生的話學生票 90 元，否則全票 120 元。」直接寫程式很容易漏掉情況。比較穩的做法是先在紙上畫出決策樹（上圖），確認每一種人都會走到一片葉子，再照著樹寫程式：

func ticket(age int, student bool) {
	kind := ""
	price := 0
	if age < 6 {
		kind = "免費"
		price = 0
	} else if age < 12 || age >= 65 {
		kind = "半票"
		price = 60
	} else if student {
		kind = "學生票"
		price = 90
	} else {
		kind = "全票"
		price = 120
	}
	fmt.Println(age, "歲", kind, price, "元")
}

func ticketDemo() {
	ticket(3, false)
	ticket(8, false)
	ticket(20, true)
	ticket(20, false)
	ticket(70, true)
}

輸出

3 歲 免費 0 元
8 歲 半票 60 元
20 歲 學生票 90 元
20 歲 全票 120 元
70 歲 半票 60 元
  • 樹的每一層問題，依序變成 if、else if、else if；最後一片葉子變成 else。
  • 第二個問題用 || 把兩種半票的情況合在一起：小孩或長者，任一種成立就是半票。
  • 70 歲的學生買到的是半票，不是學生票，因為半票的問題排在前面。順序代表優先權：符合好幾種優待時，先問到的那一種勝出。規則的優先順序如果不同，就要調整問題的順序。

檢查這類程式時，每一片葉子至少要試一個值，再試每個邊界的兩側：5 和 6 歲、11 和 12 歲、64 和 65 歲。練習 1 的運費和練習 4 的停車費都可以先畫樹再寫。

4. for：重複做

想印出 1 到 1000，不可能寫一千行 Println。迴圈（loop）讓同一段程式重複執行，Go 只有一種迴圈，就是 for：

func countdown() {
	for i := 3; i >= 1; i-- {
		fmt.Println(i)
	}
	fmt.Println("發射")
}

輸出

3
2
1
發射

for 後面用兩個分號隔成三段，就是迴圈的三個要素：

  1. 起點 i := 3：建立一個變數，在迴圈開始前做一次。
  2. 條件 i >= 1：每一圈開始前檢查，成立才執行大括號裡的內容，不成立就離開迴圈。
  3. 更新 i--：每一圈的內容執行完之後做，讓 i 往「條件不成立」的方向前進。

追蹤一次：i 是 3，3 >= 1 成立，印 3，i 變 2；2 >= 1 成立，印 2，i 變 1；1 >= 1 成立，印 1，i 變 0；0 >= 1 不成立，離開迴圈，接著執行迴圈後面的「發射」。內容一共執行了 3 次，條件檢查了 4 次，最後一次是不成立的那次。

func laps() {
	for lap := 1; lap <= 5; lap++ {
		fmt.Println("第", lap, "圈")
	}
}

輸出

第 1 圈
第 2 圈
第 3 圈
第 4 圈
第 5 圈

這是最常見的形式：從 1 數到 5。迴圈裡可以使用 lap，每一圈的值都不同。i、lap 這種用來數圈數的變數叫迴圈變數，它只在迴圈裡有效，迴圈結束後就不能用了。想跑 n 圈，可以寫 lap := 1; lap <= n，也可以寫 lap := 0; lap < n；兩種都對，但要搭配好，起點和條件差一就會多跑或少跑一圈。

5. 計數器與累加器

迴圈最常見的用途，是一圈一圈「累積」出一個結果。有兩個固定的套路，學會了就能解決一大半的問題。

累加器：把東西加起來

func sumTo100() {
	total := 0
	for i := 1; i <= 100; i++ {
		total += i
	}
	fmt.Println(total)
}

輸出

5050

累加器（accumulator）是一個在迴圈之前建立、從 0 開始的變數，每一圈加上這一圈的值。用追蹤表看前幾圈：

圈itotal（這圈結束後）
開始前0
第 1 圈11
第 2 圈23
第 3 圈36
………
第 100 圈1005050

計數器：數一數有幾個

func countMultiples() {
	count := 0
	for i := 1; i <= 30; i++ {
		if i%3 == 0 {
			count++
		}
	}
	fmt.Println(count)
}

輸出

10

計數器（counter）也是從 0 開始，但只在條件成立時加 1。這裡把迴圈和 if 組合起來：每一圈問「i 是 3 的倍數嗎」（除以 3 餘數是 0），是就 count++。1 到 30 裡有 3、6、9……30，一共 10 個。

每一圈加的量也可以變

func savings() {
	daily := 10
	total := 0
	for day := 1; day <= 10; day++ {
		total += daily
		daily += 10
	}
	fmt.Println(total)
}

輸出

550

第 1 天存 10 元、第 2 天 20 元……第 10 天 100 元。daily 記住「今天要存多少」，每一圈先加進 total，再為明天多加 10 元。這兩行的順序很重要：反過來寫，第一天就會存成 20 元。

記住兩個套路的共同點：結果變數要在迴圈外面、迴圈之前建立。寫在迴圈裡面的話，每一圈都會重新變回 0（常見錯誤 3）。

6. 只寫條件的 for、break 與 continue

有時候事先不知道要跑幾圈，只知道什麼時候該停。這時 for 後面只寫條件就好，其他語言把這種迴圈叫做 while：

func bounce() {
	height := 100
	times := 0
	for height >= 5 {
		height = height / 2
		times++
		fmt.Println("第", times, "次彈起", height, "公分")
	}
}

輸出

第 1 次彈起 50 公分
第 2 次彈起 25 公分
第 3 次彈起 12 公分
第 4 次彈起 6 公分
第 5 次彈起 3 公分

球從 100 公分落下，每次彈回一半的高度。for height >= 5 的意思是「高度還有 5 公分以上，就繼續」。起點（height := 100）寫在迴圈前面，更新（height = height / 2）寫在迴圈裡面，三個要素還是都在，只是位置不同。第 5 次彈起只剩 3 公分（6 / 2，整數除法），條件不成立，迴圈結束。

break：找到了就離開

func firstMultiple() {
	for n := 51; n <= 100; n++ {
		if n%7 == 0 {
			fmt.Println(n)
			break
		}
	}
}

輸出

56

break 立刻結束整個迴圈，不管條件還成不成立。找東西的時候，找到第一個就不必再找下去了。n 從 51 開始一個一個試，試到 56 是 7 的倍數，印出來後 break，57 到 100 都不會再試。

continue：跳過這一圈

func openDays() {
	for day := 1; day <= 7; day++ {
		if day == 3 {
			continue
		}
		fmt.Println("第", day, "天營業")
	}
}

輸出

第 1 天營業
第 2 天營業
第 4 天營業
第 5 天營業
第 6 天營業
第 7 天營業

continue 跳過這一圈剩下的內容，直接進入下一圈（會先做更新 day++）。第 3 天公休，所以「第 3 天營業」沒有印出來，但迴圈沒有結束，第 4 天照常。break 是「整個不做了」，continue 是「這次不做了」。

7. 巢狀迴圈

迴圈的大括號裡可以再放一個迴圈，叫做巢狀迴圈（nested loop）。處理「列和欄」「排和座位」這類二維的東西時一定會用到：

func seats() {
	for row := 1; row <= 3; row++ {
		for seat := 1; seat <= 4; seat++ {
			if seat > 1 {
				fmt.Print(" ")
			}
			fmt.Print(row, "-", seat)
		}
		fmt.Println()
	}
}

輸出

1-1 1-2 1-3 1-4
2-1 2-2 2-3 2-4
3-1 3-2 3-3 3-4

外層的 row 是第幾排，內層的 seat 是第幾個座位。fmt.Print 和 Println 一樣會印出東西，但最後不換行，所以同一排的座位會印在同一行；內層迴圈結束後的 fmt.Println() 只負責換行。if seat > 1 讓座位之間有空白，但第一個座位前面沒有。

內層迴圈的條件也可以用到外層的變數，畫出形狀：

func triangle() {
	for row := 1; row <= 4; row++ {
		for col := 1; col <= row; col++ {
			fmt.Print("*")
		}
		fmt.Println()
	}
}

輸出

*
**
***
****

內層的條件是 col <= row：第 1 列印 1 顆、第 2 列印 2 顆，以此類推。巢狀迴圈的總圈數是相乘的，外層 1000 圈、內層 1000 圈就是一百萬次，資料多的時候要留意速度。練習 5 要畫一個靠右對齊的三角形。

8. 無窮迴圈

條件永遠成立的迴圈叫無窮迴圈（infinite loop）。最常見的原因是忘了更新：

func main() {
	cups := 0
	for cups < 3 {
		fmt.Println("倒一杯，目前有", cups, "杯")
	}
	fmt.Println("倒好了")
}

cups 一直是 0，cups < 3 永遠成立，程式會不停地印同一行。這支程式放在獨立的資料夾裡，你可以自己執行看看。下面用 head -3 只看前三行（macOS、Linux 才有這個指令）：

go run ./chapters/pre-3-decisions/forever | head -3

輸出

倒一杯，目前有 0 杯
倒一杯，目前有 0 杯
倒一杯，目前有 0 杯

直接執行的話，畫面會一直捲動停不下來。這時按 Ctrl-C（按住 Ctrl 再按 C），終端機就會強制停止程式。程式「卡住」、沒有反應、也沒有結束的時候，第一個要懷疑的就是無窮迴圈。

另一種：條件永遠等不到

func neverTen() {
	rounds := 0
	for n := 1; n != 10; n += 2 {
		fmt.Print(n, " ")
		rounds++
		if rounds == 8 {
			fmt.Println("… 已經跑了 8 圈，n 永遠不會剛好等於 10")
			break
		}
	}
}

輸出

1 3 5 7 9 11 13 15 … 已經跑了 8 圈，n 永遠不會剛好等於 10

這次有更新（n += 2），n 也一直在變，但 n 是 1、3、5、7、9、11……全是奇數，永遠不會剛好等於 10，n != 10 就永遠成立。為了不讓示範停不下來，這裡加了一個「跑到第 8 圈就 break」的保護。如果條件寫成 n < 10，n 變成 11 時條件就不成立了。迴圈條件盡量用 <、<= 這種「越過就停」的比較，少用 != 這種「剛好才停」的比較。

寫完迴圈之後，用這兩個問題檢查：

  • 條件裡用到的變數，每一圈都會改變嗎？
  • 它是往「讓條件不成立」的方向改變嗎？例如條件是 i >= 1，更新卻寫成 i++，i 就會越來越大，永遠不會小於 1。

常見錯誤

1. else if 的順序寫反

範圍大的條件放前面，範圍小的永遠輪不到（第 2 節）。從最嚴格的條件開始問。

2. 邊界差一

< 和 <= 只差一個符號，結果就多一圈或少一圈、多算一天或少算一天。寫完後用邊界上的值追蹤一次：剛好 60 分、剛好存到目標金額、只有一個數的範圍。練習 6、7 都是這類 bug。

3. 累加器寫在迴圈裡面

把 total := 0 放進 for 的大括號裡，每一圈都會重新建立一個 0，最後只剩最後一圈的值，而且迴圈結束後還用不到它。結果變數要寫在迴圈之前。

4. 忘了更新，或更新方向相反

條件永遠成立就停不下來（第 8 節）。按 Ctrl-C 停止，再檢查條件裡的變數有沒有朝正確的方向改變。

5. 在條件裡把 == 寫成 =

package main

import "fmt"

func main() {
	score := 60
	if score = 60 {
		fmt.Println("剛好及格")
	}
}

編譯錯誤

./main.go:7:11: syntax error: cannot use assignment score = 60 as value

一個等號是指定，不是比較，不能當成條件。改成 score == 60。

6. 把 else 換到下一行

package main

import "fmt"

func main() {
	score := 72
	if score >= 60 {
		fmt.Println("及格")
	}
	else {
		fmt.Println("不及格")
	}
}

編譯錯誤

./main.go:10:2: syntax error: unexpected keyword else, expected }

Go 會在 } 後面換行的地方自動當成一行結束，下一行的 else 就接不上了。要寫成 } else {。

    測試：TestSumOdd。

    提示

    累加器加上 if：i % 2 == 1 時才加。另一個寫法是讓 i 從 1 開始、每圈 i += 2，就只會走過奇數。n 小於 1 時迴圈一圈都不會跑，total 自然是 0。

  3. 進階練習 3：幾位數

    數一數一個整數有幾位數。

    func CountDigits(n int) int {
	// TODO: 實作
	return 0
}

    測試：TestCountDigits。

    提示

    每除以 10，就少掉最後一位：2026、202、20、2。用只寫條件的 for，一邊除一邊數。小心 0：它是 1 位數，但「除到變成 0 為止」的寫法會數出 0 位。

  4. 進階練習 4：停車費

    前 30 分鐘免費，之後每 30 分鐘 20 元（不足 30 分鐘也算 30 分鐘），一次最多 200 元。

    func ParkingFee(minutes int) int {
	// TODO: 實作
	return 0
}

    測試：TestParkingFee。

    提示

    分三步：先處理 30 分鐘以內；再算超過的分鐘數要收幾個 30 分鐘（「不足也算」就是無條件進位，可以用迴圈每次扣 30 來數，或用 (超過的分鐘 + 29) / 30）；最後如果超過 200 就改成 200。

  5. 挑戰練習 5：靠右的三角形

    畫出靠右對齊的星號三角形，結果是一個字串。

    func RightTriangle(n int) string {
	// TODO: 實作
	return ""
}

    測試：TestRightTriangle。

    提示

    第 row 列（共 n 列）先有 n - row 個空白，再有 row 顆星。外層迴圈走每一列，裡面放兩個內層迴圈：一個加空白、一個加星號。用一個字串變數當累加器，s += "*" 把字接上去。換行 "\n" 加在每一列的前面（第一列除外），最後一列後面就不會多一個換行。

  6. 找錯練習 6：區間的和

    從 from 加到 to，但總是少加了最後一個數。

    func SumRange(from, to int) int {
	total := 0
	for i := from; i < to; i++ {
		total += i
	}
	return total
}

    測試：TestSumRange。

    提示

    用 SumRange(5, 5) 追蹤一次：i 從 5 開始，條件 i < to 是 5 < 5，一圈都沒跑。

  7. 找錯練習 7：存錢要幾天

    剛好存到目標金額的那一天，程式卻多算了一天。

    func DaysToSave(target, daily int) int {
	days := 0
	total := 0
	for total <= target {
		days++
		total += daily
	}
	return days
}

    測試：TestDaysToSave。

    提示

    用目標 100、每天 50 畫追蹤表：第 2 天結束時 total 是 100，這時條件 total <= target 成立嗎？迴圈的條件應該是「還沒達到目標」。

參考解答：先自己寫完再看。

重點回顧

  • if 條件成立執行第一個大括號，否則執行 else；沒有 else 就直接往下走。
  • else if 從上往下問，第一個成立的就決定結果，所以要從最嚴格的條件問起。
  • 規則複雜時先畫決策樹，每片葉子和每個邊界都要測試。
  • for 的三個要素：起點只做一次，每圈先檢查條件，內容執行完再更新。
  • 累加器和計數器都在迴圈之前從 0 開始；累加器加上值，計數器在條件成立時加 1。
  • 不知道要跑幾圈時，for 後面只寫條件。
  • break 結束整個迴圈，continue 只跳過這一圈。
  • 巢狀迴圈：外層每走一圈，內層就完整跑一次，總次數是相乘。
  • 條件永遠成立就是無窮迴圈：檢查更新的方向，少用 != 當條件，卡住時按 Ctrl-C。
