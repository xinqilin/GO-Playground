struct 與方法

struct 是一張表格，把相關的欄位放在一起；方法是綁在這張表格上的函式。

看圖

最小範例

type Point struct{ X, Y int }

func (p Point) Dist2() int { return p.X*p.X + p.Y*p.Y } // 只讀：value receiver

func (p *Point) Move(dx, dy int) { p.X += dx; p.Y += dy } // 要改：pointer receiver

type Animal struct{ Name string }

func (a Animal) Hello() string { return "我是" + a.Name }

type Dog struct {
	Animal // 嵌入：欄位和方法都被提升
	Breed  string
}

func main() {
	p := Point{X: 3, Y: 4}
	p.Move(1, 1)
	d := Dog{Name: "小白", Breed: "米克斯"} // Go 1.27 起可以這樣寫
	fmt.Println(p, p.Dist2(), d.Hello())
}

輸出

{4 5} 41 我是小白

工程師筆記

  • receiver 怎麼選：要修改、struct 很大、或含有不能複製的欄位（例如 sync.Mutex）就用指標；同一個型別的方法最好統一。
  • 用變數呼叫 pointer receiver 的方法時，Go 會自動取地址；但 map 裡的值、函式回傳值不能取地址，就不能這樣呼叫。
  • 嵌入是組合：被嵌入型別的方法拿到的仍是它自己那一份，不知道外面包著 Dog。沒有 override，也沒有透過嵌入的多型。
  • 欄位大寫開頭才會匯出；encoding/json 只看得到匯出的欄位，用 struct tag 改 JSON 名稱（第 22 章）。
  • Go 1.27 起，struct 字面值可以直接用被提升的欄位當 key：Dog{Name: "小白"}。
  • 建構子只是慣例：寫一個 NewXxx 函式回傳 *Xxx。零值就能用的型別不需要建構子。
