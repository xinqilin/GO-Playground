變數與型別

變數是貼了名字的盒子，而且每個盒子只收一種東西。

看圖

最小範例

func main() {
	var a int = 10 // 完整寫法
	var b = 20     // 由右邊的值推斷型別
	c := 30        // 簡短宣告，只能在函式裡用
	a, b = b, a    // 交換

	var zero string // 沒給值：零值 ""
	const (
		Small  = iota // 0
		Medium        // 1
		Large         // 2
	)
	f := float64(c) / 4 // 型別轉換要明說
	fmt.Println(a, b, c, zero == "", Large, f)
}

輸出

20 10 30 true 2 7.5

工程師筆記

  • := 只能用在函式裡；套件層級的變數要用 var。
  • 宣告了卻沒用到的區域變數是編譯錯誤。
  • 數字型別不會自動轉換，連 int 和 int64 都不能直接相加。
  • 沒有型別的常數（例如 const big = 1 << 100）精度很高，用到時才決定型別，只要結果放得進去就好。
  • 整數溢位會繞回去：int8 的 127 加 1 變成 -128，不會丟出錯誤。
  • int 的大小跟著平台走，64 位元系統上是 64 bit；需要固定大小就用 int32、int64。byte 是 uint8 的別名，rune 是 int32 的別名。
