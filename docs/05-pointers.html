指標

一張寫著門牌的紙條：拿著它，就能找到並改動原本的變數。

看圖

最小範例

func addOneValue(n int)    { n++ }  // 拿到影印本
func addOnePointer(n *int) { *n++ } // 拿到門牌

func main() {
	x := 5
	p := &x // p 的型別是 *int
	*p = 10 // 照門牌改：x 變成 10
	fmt.Println(x, *p, p == &x)

	a, b := 1, 1
	addOneValue(a)
	addOnePointer(&b)
	fmt.Println(a, b)
}

輸出

10 10 true
1 2

工程師筆記

  • Go 一律傳值。slice、map、channel 本身是一個小小的描述子，裡面記著底層資料的位置；複製描述子不會複製底層資料，所以函式裡改元素，呼叫端看得到（細節在第 06、07 章）。
  • 回傳區域變數的地址是安全的。編譯器會做 escape analysis，變數離開函式後還會被用到，就放到 heap；go run -gcflags=-m 會印出 moved to heap: c。
  • 沒有指標運算，p++ 編譯不過。
  • 對 nil 解參考會 panic：invalid memory address or nil pointer dereference。
  • 什麼時候用指標：函式要改到呼叫端的值、struct 很大不想複製、要用 nil 表示「沒有值」。小的值直接傳，通常比較簡單。
  • Go 1.26 起 new 可以直接給初始值：new(7) 得到一個指向 7 的 *int，填 JSON 的選填欄位很方便。
